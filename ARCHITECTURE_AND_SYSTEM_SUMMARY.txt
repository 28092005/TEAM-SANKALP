1. EXECUTIVE SUMMARY & INITIAL PURPOSE
--------------------------------------------------------------------------------
The Context-Aware Application Agent is a specialized Enterprise Business Intelligence (BI)
and E-Commerce operations platform. Rather than acting as a standard conversational chatbot,
it implements an autonomous Context-Aware Agent Orchestrator. 

The agent operates with full awareness of the application's runtime state:
- Current viewport/route (e.g., Executive Dashboard, Sales Report, Regional Analysis)
- Active widget registry and semantic UI capabilities
- Dynamic filtering slots (Region, Product Category, Order Status, Date Range)
- Underlying transactional and tabular data (Orders, SKUs, Cohorts, Monthly Trends)

The agent translates unstructured natural language intents (typed or voice) into concrete UI
navigation actions, atomic filter mutations, real-time statistical aggregations, automated data
exports (PDF/CSV), and autonomous multi-step workflows with zero hallucination.


2. COMPLETE SYSTEM LAYERS (3-TIER ARCHITECTURE)
--------------------------------------------------------------------------------
The system is architected around a strict Three-Tier Agent Blackboard Paradigm:

[ TIER 1: INTENT DECOMPOSITION & HOST AGENT ORCHESTRATOR ]
---------------------------------------------------------
- Receives natural language queries via text or Web Speech API.
- Guardrail Verification: Scans queries against security and safety policies, actively
  blocking destructive mutations (e.g., DROP TABLE, DROP DATABASE, unauthorized role escalation).
- Intent Disambiguation & Slot Filling: Extracts temporal windows (e.g., "last quarter",
  "Q3", "MoM"), geographic regions ("Karnataka", "North", "South"), order statuses ("Cancelled",
  "Delivered"), and product categories ("Electronics", "Home & Kitchen").
- Sub-Task Planning: Generates a directed execution DAG (Directed Acyclic Graph) specifying
  atomic actions: NAVIGATE -> APPLY_FILTER -> ANALYZE_DATA -> REGENERATE_DATA.

[ TIER 2: MEMORY, BLACKBOARD & KNOWLEDGE GRAPH BUS ]
---------------------------------------------------
- Component Metadata Catalog: A semantic registry (`APP_METADATA_CATALOG`) indexing every
  page, widget ID, widget visual type (KPI cards, charts, geo maps, tables), and supported filter slots.
- Vector & Keyword RAG Matching: Computes keyword and semantic overlap between the user's intent
  and the catalog to rank target viewports and relevant widgets.
- Shared Blackboard Event Bus: Maintains an immutable live trajectory of operational telemetry
  (`BlackboardLog[]`), logging timestamps, tiers, events, details, and status flags (info, success,
  warning, error).
- Session Memory: Retains conversational turns and prompt history for contextual follow-ups.

[ TIER 3: EXECUTION APPAGENT & SYNCHRONIZATION ENGINE ]
------------------------------------------------------
- UI State Dispatcher: Synchronously updates React state (`currentPage`, `filterState`) across the
  entire application, causing reactive re-rendering of all connected charts and tables.
- Analytic Synthesis Engine: Computes real-time deterministic statistics (e.g., total sales volume,
  growth percentages, cancellation rates, top-performing SKUs, cohort spending) matching filtered data.
- Voice/TTS Synthesizer: Utilizes the browser Web Speech Synthesis API to vocalize agent summaries
  for hands-free executive accessibility.
- Export Engine: Generates client-side CSV and formatted, printable PDF executive reports.


3. TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Core Framework: React 19 (React 19.0.1) with Strict TypeScript (ES2022 / TS 7.0.2).
- Bundler & Dev Server: Vite 8 (Vite 8.3.0) with `@vitejs/plugin-react`.
- Styling & Design System: Tailwind CSS v4 (`@tailwindcss/vite` v4.3.3) with `@import "tailwindcss";`.
- Icons & Visual Assets: Lucide React (`lucide-react` v0.546.0).
- Charting & Visualizations: Recharts (`recharts` v3.10.1) for Bar Charts, Area Charts,
  Donut/Pie Charts, and Line Charts.
- Animation & Transitions: Motion (`motion` v12.23.24) and Tailwind CSS transitions.
- AI & LLM SDK: `@google/genai` (v2.4.0) with support for Gemini API integration and fallback
  rule-based heuristic engines for ultra-low latency and offline execution.
- Export & Document Generation: Native CSV generation with RFC-4180 escaping and native CSS
  Print Stylesheet for pixel-perfect PDF export.

5. STEP-BY-STEP RUNTIME EXECUTION LIFECYCLE
--------------------------------------------------------------------------------
When a user submits a prompt (e.g., "Show cancelled orders in North region"):

1. Ingestion: AppContext captures prompt and sets `isAgentThinking = true`.
2. Guardrail Scan: Prompt is checked for destructive commands or privilege escalation.
3. RAG Knowledge Graph Retrieval: Metadata is scanned. "Order Management" is scored as the top
   matching route based on keywords ("cancelled", "orders").
4. Slot Filling & Planning:
   - Target Page: `order-management`
   - Filter Mutated: `status = 'Cancelled'`, `region = 'North'`
   - Formulates Action Sequence: NAVIGATE -> APPLY_FILTER -> ANALYZE_DATA
5. Trajectory Logging: Events are pushed to the live Blackboard Log stream.
6. Reactive State Dispatch: AppContext updates `currentPage` and `filterState`. UI switches view
   and filters the table instantaneously.
7. Analytics Computation: Engine calculates exact counts, revenue impact, and percentage of
   cancelled orders in the North zone.
8. Message & Insights Generation: Agent outputs conversational response, analytical cards,
   action checklist, and suggested follow-ups.
9. Optional Audio Synthesis: If voice is toggled on, speech synthesis reads the summary aloud.
